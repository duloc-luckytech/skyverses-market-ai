# Legacy Docs (archived)

Các file md/txt từ exploration sessions, audit reports, status snapshots, phase summaries cũ. **Không sync với code hiện tại** — chỉ giữ làm history.

**Có thể xoá hẳn nếu không dùng tới trong 1-2 tháng nữa.**

## Nhóm file

- `CODEBASE_*` — exploration session reports (đã thay bằng `docs/source-map/`)
- `EXPLORATION_*`, `PHASE3_*`, `SCAN_*` — exploration sessions
- `SESSION_*`, `PROJECT_*`, `COMPREHENSIVE_*` — status reports
- `FINAL_*`, `STATUS.txt`, `READY_FOR_QA.txt`, `DELIVERY_SUMMARY.txt` — phase done
- `AUDIT_*`, `CREDITS_PRICING_AUDIT.md` — audit cũ
- `CROP_*`, `bug_analysis.md`, `code_reference.md`, `DETAILED_BUG.md` — bug fix sessions
- `BLOG-*`, `blog-*.md` — blog exploration
- `DOCX_*` — DOCX import phase
- `MARKETPLACE_*` (trừ `_VISUAL_GUIDE` đã chuyển reference) — exploration cũ
- `PAPERCLIP_*` (trừ `_DEVELOPMENT_ROADMAP` và `_IMPLEMENTATION_EXAMPLES`) — audit cũ
- `README_AUDIT/BUG/EXPLORATION/MARKETPLACE/SORTING/TESTING.md` — phase READMEs
- `QUICK_*`, `START_*` — quick refs cũ
- `WORKSPACE_*` (trừ `_ARCHITECTURE.txt` đã chuyển reference) — exploration
